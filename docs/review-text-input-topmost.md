# テキスト入力と最前面モードの修正

- テキスト追加・再編集のダイアログに編集画面のTopMostを引き継ぐ。入力画面が編集画面の背後に隠れて操作不能に見える経路を解消する。
- キャンバスのMouseDownからモーダル入力を開く前にマウス捕捉を解除する。入力画面へマウス操作が届くようにする。
- キャプチャ／プレビュー終了時に、最前面ONの場合はメイン画面のネイティブ表示順を再適用する。Excelへのキーボードフォーカスは奪わない。
- 下部の操作案内を削除する。編集範囲不足などのエラー通知は残す。

## 検証

SDK 9.0.304、Release。通常テスト120件成功。追加したSTAテストは実際にテキスト入力ダイアログを開き、マウス捕捉解除・TopMost引継ぎ・Enter追加後の編集画面維持を確認する。

Excel連携を含む一括テストは中断し、今回変更に対応する通常テストへ絞って実行した。複数アプリ・モニター間での表示順と日本語IMEを含む手動操作の全組合せは未検証。

配布バージョン: 0.1.0-preview.23。
