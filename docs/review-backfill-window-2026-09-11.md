# CASE後戻り配置・メイン画面サイズの修正

対象: 0.1.0-preview.28 / .NET SDK 9.0.304

## 自動配置

参照ブックのコピーで、1-1 NEW → 1-2 NEW → 1-2 OLD → 1-1 OLD の順に配置する検証を追加した。小さい画像だけでは失敗しなかったが、1-1の末尾行に既存内容を置くと「追加行を3回補正しても…」を再現した。

従来はCASE末尾の直前に行を挿入していたため、末尾の内容も毎回下へ移動し、必要な余白が確保できなかった。後続CASEがある場合は、次のCASE番号の直前（現在の末尾の次行）へ挿入する。最終CASEのUsedRangeを伸ばす処理、および再解析・上限・失敗時の取り消しは維持した。

検証対象は罫線あり／部分的な罫線なし／罫線なしの参照ブック。OLDなしのブックは従来のNEW追加配置を検証する。参照元は変更せず、終了時にSHA-256の一致を確認する。

## メイン画面

最小サイズの算出を無制約のPreferredSizeから最小コンテンツサイズの計測へ変更し、拡張されたパーセント幅の影響を避けた。最小クライアント幅760・高さ370とスクロールバーなしの方針は維持する。

メイン画面の単独STAチェックで、幅400・高さ100拡大 → 最小サイズ再計測 → 元のサイズへの縮小を確認した。ただし、この環境では変更前も同チェックは成功しており、ユーザー環境での縮小不能そのものは再現できていない。実際の表示倍率・モニター構成で再確認が必要。

メイン画面のDisposeはプロセス全体のExcelセッション登録を停止するため、この単独チェックは通常テスト群には組み込まない。同一プロセスで併走させた際のセッション登録テスト失敗は、単独チェックを分離して解消した。
