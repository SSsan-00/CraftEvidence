## 最終レビュー対応

| 指摘 | 対応 |
|---|---|
| 自動配置の行とShapeが別履歴 | Shapeを逆順削除してから挿入行を戻し、Redoは行→Shapeの順で行う単一履歴へ統合 |
| 差し替え・削除をUndoできない | 操作前に管理ShapeをPNGへ一時退避し、位置・寸法・メタデータを保持して復元する履歴を追加 |
| 操作の多重実行 | Form全体の排他ガードを追加し、ボタンとCtrl+Z/Ctrl+Yを共通制御 |
| 左右余白設定が未接続 | 自動配置の利用可能幅計算へ設定値を注入 |
| 通常配置・Redoの余白不整合 | 全配置へ余白を渡し、履歴登録時の値を固定 |
| 配置後に移動したShapeをUndoで削除 | 位置・寸法・メタデータを保持し、完全一致しなければ安全停止 |
| 差し替えUndoで原寸に戻らない | Undo/Redo用のexact geometry経路を追加し、実Excelで寸法復元を検証 |
| PNG退避がClipboardを上書き | 対応形式を退避し、sequence競合がなければ復元。競合時は新規Clipboard通知を再処理 |
| 回転・crop済み管理画像の不可逆性 | 操作前に回転/cropを検証し、初期状態でなければ安全停止 |
| 未接続のCase行間隔設定 | UIと設定モデルから削除。Case間隔は実シート境界信号から解析 |
| 自動解析がExcel状態を変える | 対象SheetがActiveでない場合は安全停止し、Snapshot取得ではWorkbook/SheetをActivateしない |
| 旧版文書との矛盾 | READMEと実装状態をpreview.12へ同期 |
| 行削除Undoの書式復元不足 | 削除行を一時Excelブックへネイティブ退避し、行高・罫線・入力規則・条件付き書式を復元 |
| Undo/Redo中のユーザー変更 | 行位置・数式・主要書式のfingerprint不一致時に安全停止 |
| 範囲外参照の破損 | 対象Worksheet数式、Workbook名前定義、印刷範囲を退避・復元。別Sheetに数式があるWorkbookは行削除を安全停止 |
| 最終Case境界の削除 | Case終端行を削除計画から常に除外 |
| 高い画像の差し替え失敗 | 旧画像の下へ行を追加し、計算済み寸法を差し替えへ渡し、例外時も追加行を補償 |
| 単一画像UIのみ | 複数ファイル選択による一括自動配置と一括Undo/Redoを追加 |
| Case移動不足 | 前／次Caseボタンを追加し、移動先セルへフォーカス |

## 安全境界

- Workbook identity、Window token、ReadOnly、Sheet保護、EnableEventsを変更直前に再検証する。
- Snapshot fingerprintが変化した場合は自動配置を中止する。
- 複数ステップ配置は途中失敗時にShape→挿入行の逆順で補償する。
- 削除対象行に値、数式、コメント、リンク、Shape、結合があれば削除しない。
- Workbookは自動保存しない。参照フォルダは変更しない。

## 環境横断の手動受入項目

100/150/200% DPI、複数モニター、Office x64、clean VM、OneDrive/ネットワークパス、20画像連続操作は、当該ホスト単体の自動検証ではなくリリース時の環境横断確認対象とする。

行削除Undoは削除行をネイティブExcel形式で一時退避し、空セルの独自行高・罫線・入力規則・条件付き書式を含めて復元する。対象Worksheetの参照数式、Workbook名前定義、印刷範囲も退避する。別Sheetに数式がある場合、または安全確認範囲が250,000セルを超える場合は行削除を安全停止する。削除後またはUndo後に対象状態が変更されている場合も履歴操作を行わない。
